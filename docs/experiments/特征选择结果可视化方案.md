# 特征选择结果可视化方案

## 目标

将347维扩展手工特征的组合搜索结果整理为一个可离线打开、可重复生成的单文件HTML。
页面不依赖CDN或远程JavaScript，图表直接嵌入HTML，复制结果目录后仍能查看。

页面依次回答四个问题：

1. 最终OOF指标如何，类别敏感度和特异性是否失衡；
2. 五折验证与测试表现是否稳定；
3. 哪些特征组合、选择器、维度和模型更有效；
4. 哪些特征在不同折中反复入选。

## 页面组成

| 模块 | 数据源 | 用途 |
|---|---|---|
| OOF指标卡与对比图 | `oof_metrics.json` | 展示accuracy、balanced accuracy、macro F1、AUC等 |
| 混淆矩阵 | `oof_metrics.json` | 同时显示数量和按真实类别归一化比例 |
| 五折稳定性 | `fold_best.csv` | 对比每折验证accuracy和独立测试accuracy |
| 每折方案表 | `fold_best.csv` | 记录特征组、选择器、维度和模型 |
| 实际候选漏斗 | `validation_grid.csv` | 展示每折从11组、33个初筛候选到唯一方案的收缩过程 |
| 五折赛程图 | `validation_grid.csv`、`fold_best.csv` | 用晋级连线展示11组→3组→每折冠军方案 |
| 五折初筛热图 | `validation_grid.csv` | 标出每折进入第二阶段的前三个特征组 |
| 五折精筛热图 | `validation_grid.csv`、`fold_best.csv` | 展示选择器×维度搜索并标记最终胜出单元格 |
| 完整组合初筛 | `validation_grid.csv` | 比较11类特征组合和3类机器学习模型 |
| 维度趋势 | `validation_grid.csv` | 查看各选择器在候选维度上的验证趋势 |
| 高频特征 | `selected_feature_frequency.csv` | 展示跨折重复入选情况 |

维度趋势只覆盖每折进入第二阶段的前三个特征组，因此属于探索性图表，不能作为
跨全部特征组的严格全局排名。高频特征同样不能直接用于同一五折的固定全局掩码，
否则会把跨折信息重新带回评价流程。

## 生成命令

从仓库根目录运行：

```powershell
& C:\Users\cgy_3\miniconda3\envs\pytorch-env\python.exe -B `
  scripts\evaluation\visualize_feature_selection.py
```

默认输出：

```text
features/expanded347/selection_ml_grid_e3_v1/feature_selection_dashboard.html
```

生成HTML只读取已经完成的CSV和JSON，不会重新拟合特征选择器或分类器。
