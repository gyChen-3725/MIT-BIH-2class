# 347维扩展特征：选择方法、维度与机器学习组合搜索

## 目标

在不读取测试标签的前提下，同时比较：

- 特征组合：完整HRV、原始ECG、QRS、ECG＋QRS、非EDR融合、三路EDR、
  全EDR、旧263维、三路EDR＋全部新增特征、完整347维等11组；
- 特征选择：ANOVA F、互信息、L1线性SVM、随机森林重要性、mRMR；
- 候选维度：16、32、48、64、96、128、192、263，以及不选择的347维基线；
- 分类器：逻辑回归、随机森林、直方图梯度提升树。

每折先用33次拟合筛查11组完整特征组合，只让验证集最好的3组进入列级选择。
按照当前维度设置，完整五折最多约1820次模型拟合；实际数量取决于每折进入第二阶段
的特征组维度。scikit-learn主要使用CPU，4090不会明显加速这组实验。

| 组合名 | 维度 | 构成 |
|---|---:|---|
| `hrv_all` | 32 | 8项基础HRV＋24项扩展HRV |
| `ecg` | 34 | 原始ECG统计、频谱和复杂度 |
| `qrs` | 26 | QRS形态分布 |
| `ecg_qrs` | 60 | 原始ECG＋QRS形态 |

## 两阶段搜索到底做了什么

### 第一阶段：完整特征组初筛

第一阶段没有进行列级特征选择。对每一折的11个完整特征组，分别使用以下3种
分类器训练和验证：

- 逻辑回归（Logistic Regression，LR）；
- 随机森林（Random Forest，RF）；
- 直方图梯度提升树（HistGradientBoosting，HGB）。

因此每折第一阶段共有 `11个特征组 × 3个分类器 = 33个候选方案`。每个特征组
取3个分类器中的最高验证集accuracy作为该组的初筛成绩，再按同分规则比较macro F1、
balanced accuracy和ROC AUC。每折成绩最高的3个特征组进入第二阶段。代码并没有
预先只使用RF和HGB；本次结果看起来主要由RF/HGB晋级，是因为LR的验证表现通常较低。

```text
一个完整特征组
├── LR
├── RF
└── HGB
     ↓  取该组最高验证成绩
11个组排序后，每折前三组晋级
```

### 第二阶段：晋级组内部的列级选择

第二阶段只处理当前折晋级的3个特征组。对每个组穷举：

```text
3个晋级特征组
× 5种特征选择器
× 小于该组完整维度的候选维度
× 3种分类器（LR、RF、HGB）
```

五种特征选择器分别是：

| 选择器 | 排名依据 |
|---|---|
| `anova` | 每列与二分类标签之间的ANOVA F统计量 |
| `mutual_info` | 每列与标签之间的互信息 |
| `l1` | L1正则线性SVM系数绝对值 |
| `random_forest` | 随机森林特征重要性 |
| `mrmr` | 与标签最大相关、与已选列最小冗余 |

这里有两个不同角色的随机森林，不能混淆：`random_forest`选择器负责给特征列排序；
RF分类器负责使用选出的列完成最终分类。采用RF选择器时，最终分类器仍可能是LR、RF
或HGB。HGB只作为分类器，不参与特征排名。

候选维度为16、32、48、64、96、128、192、263，但只有小于当前特征组完整维度的
候选才会运行。例如60维的 `ecg_qrs` 只会搜索16、32和48维；完整60维方案已经在
第一阶段评价，不会在第二阶段重复拟合。

第二阶段结束后，程序不是只在降维方案中选冠军，而是把第一阶段的33个完整维度方案
和第二阶段所有降维方案放回同一个候选池。最终仍按验证accuracy及同分规则选择唯一
方案。因此完整维度方案可以胜出：本次Fold 3最终选择
`non_edr_with_hrv + none + 92维 + RF`，其中 `none` 表示不做列级特征选择。

可视化热图为了压缩信息，对固定的“选择器＋维度”单元格，只显示3个晋级特征组和
3种分类器中的最高验证accuracy。热图的行名是**特征选择器**，不是最终分类器；
完整获胜方案仍应以 `fold_best.csv` 为准。

## 无泄漏流程

每一折独立执行：

1. 使用完整维度在验证集筛查11种特征族组合及3个模型；
2. 只让每折验证表现最好的3个特征组合进入列级搜索；
3. 只在训练集拟合缺失值填补和特征排名；
4. 在验证集比较“特征组合＋选择器＋维度＋模型”，默认以accuracy为主指标；
5. 同分时依次比较macro F1、balanced accuracy和ROC AUC，再优先更少维度；
6. 确定组合后，在训练＋验证集重新拟合该选择器和模型；
7. 测试集只评估一次，产生该折最终预测。

三部分数据的职责不能混用：

```text
训练集：拟合候选方案的缺失值填补、特征排名和分类器
   ↓
验证集：用accuracy比较“特征组合＋选择器＋维度＋模型”
   ↓  固定最佳方案，不再修改方法或维度
训练集＋验证集：重新拟合该方案的填补、特征排名和最终分类器
   ↓
测试集：只评价一次，产生该折最终预测
```

例如验证阶段选定 `expanded_all + L1 + 64维 + HistGB` 后，最终阶段不会继续
比较其他方案，而是在训练集＋验证集上重新计算中位数填补、L1排名和HistGB模型。
重新排名后具体入选列可以变化，但选择器仍是L1、目标维度仍是64、分类器仍是HistGB。
测试集标签从不参与填补、排名、模型拟合或方案选择。若查看测试指标后再更换方案，
测试集就会退化为调参集，报告结果会产生乐观偏差。

因此五折可能选出不同维度。这是自适应选择流程的正常结果。最终报告会统计各折
所选维度及特征出现频率；不能看完测试指标后再倒推一个“最佳全局维度”。

## 输出

- `validation_grid.csv`：特征族初筛和列级选择的全部验证组合；
- `validation_dimension_summary.csv`：按特征组合、选择器、维度和模型汇总验证趋势；
- `fold_best.csv`：每折最终组合与测试指标；
- `selected_features/fold_*.json`：重拟合后的特征索引和名称；
- `selected_feature_frequency.csv`：特征跨折入选次数；
- `oof_predictions.csv`、`oof_metrics.json`：自适应五折OOF结果；
- `组合搜索报告.md`：主要结论汇总。
