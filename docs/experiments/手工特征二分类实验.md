# EDR 手工特征的二分类机器学习实验

## 对齐与评价协议

阳性类为 MIT-BIH master 中所有非 `Normal` 的标注事件，阴性类为 `Normal`。
已逐行核对 10,197 个 EDR 窗口与 master 的 `record`、`start_sample` 和二分类标签。
本实验复用 `protocols/e3_full_epoch5fold_20260913` 的**样本级冻结五折**，可与
DAEAC 的 E3 结果作协议内对照。

每折仍分训练、验证、测试三部分；模型仅在训练索引上拟合，验证集用于方案选择，
测试集只在方案确定后评价。EDR 特征中的局部基线使用当前30秒前的120秒信号，且
EDR提取使用离线零相位滤波。样本级随机划分会让相邻窗口落在不同集合，因此结果
不能解释为未见受试者泛化能力。

## 首轮固定比较

| 特征组 | 维度 | 内容 |
|---|---:|---|
| `hrv` | 8 | 短时NN/HRV时域特征 |
| `edr3` | 80 | `AM_QR`、`AM_R`、`SM_angle`各25项生理特征，加5项三路关系特征 |
| `fusion3` | 88 | `hrv`加`edr3` |
| `all` | 263 | 全10路EDR生理特征，加HRV和三路关系特征 |

单路EDR的覆盖率、最长缺口及基线覆盖率不作为模型输入。各组比较正则化逻辑回归、
随机森林和直方图梯度提升树；缺失值填补、缩放和特征选择参数只从当前训练折估计。

## 当前入口

旧263维基线和347维扩展输入现在都由本仓库的统一入口读取：

```powershell
python -u -B scripts\training\train_handcrafted_2class.py
python -B scripts\selection\optimize_feature_dimension.py --plan-only
```

第一条命令会拟合模型，必须由用户显式启动；第二条只核对组合规模，不训练。
