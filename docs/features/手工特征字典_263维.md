# EDR手工特征字典：模型输入263维

本文档由实际实现常量生成，对应 `features_30s.npz` 的10路EDR统计量、HRV和跨路关系特征。
每行数据对应一个30秒epoch；特征提取不读取标签。模型输入排除了每路EDR的3项质量字段，
因此维度为 `8 + 10×25 + 5 = 263`。索引为Python零基索引。

## 共同预处理与缺失规则

- 心搏级EDR先插值到5 Hz；整条记录去趋势后进行0.08–0.5 Hz四阶Butterworth零相位带通。
- Hilbert包络使用2秒均值平滑。频谱由30秒Hann窗Welch估计，频率分辨率约0.033 Hz。
- 当前窗口EDR覆盖率低于95%时，该路25项生理统计量均为缺失值。
- 需要历史基线的指标使用当前窗口之前120秒包络的90%分位数；历史覆盖不足95%时这些指标缺失。
- HRV仅使用相邻正常心搏；NN间期限制为0.3–2秒。少于3个NN间期时多数HRV统计量缺失。
- 模型每折只用训练集的中位数填补缺失值，并只用训练集均值和标准差做逐列标准化。

## 十路EDR来源

| 方法 | 含义 | 心搏级定义 | 原始量纲 |
|---|---|---|---|
| `am_area` | QRS面积调制 | QRS曲线与Q-S连线之间绝对面积 | ECG幅值×秒 |
| `am_qr` | Q-R幅差调制 | R点幅值减Q点幅值 | ECG幅值 |
| `am_r` | R波幅度调制 | 极性校正后的R点幅值 | ECG幅值 |
| `am_q` | Q波幅度调制 | 极性校正后的Q点幅值 | ECG幅值 |
| `sm_angle` | QRS斜率夹角调制 | Q-R上升斜率与R-S下降斜率形成的夹角 | 弧度 |
| `sm_qr` | Q-R斜率调制 | Q-R段最大一阶导数 | ECG幅值/秒 |
| `sm_rs` | R-S斜率调制 | R-S段最小导数取负值 | ECG幅值/秒 |
| `fm_qs` | QRS时长调制 | S点与Q点的时间差 | 秒 |
| `fm_rr` | R-R间期调制 | 相邻正常心搏R峰时间差，限0.25到3秒 | 秒 |
| `bm_qrs` | QRS基线调制 | 相邻Q点之间ECG的平均值 | ECG幅值 |

## 未进入263维模型输入的质量字段

每路EDR还保存 `coverage_fraction`、`longest_uncovered_seconds` 和
`baseline_coverage_fraction`，共30项。它们用于质量审计，没有进入当前分类器，
避免模型把记录缺失模式当作疾病捷径。包含这些字段时原始候选总数为293。
