# 扩展手工特征：特征选择与机器学习组合搜索

每折使用验证集 `accuracy` 选择方法、维度和模型；测试集只在选定后评价一次。
候选比较阶段的缺失值填补、特征排名和分类器只使用当前折训练集拟合。
确定特征组合、选择器、维度和模型后，在训练集＋验证集上重新拟合填补、特征排名和最终模型，
测试集始终不参与拟合或方案选择，只在最后评价一次。

## 每折的数据职责

```text
训练集：拟合候选方案的填补、特征排名和分类器
   ↓
验证集：以 accuracy 比较特征组合＋选择器＋维度＋模型
   ↓  固定最佳方案，不再修改超参数
训练集＋验证集：重新拟合该方案的填补、特征排名和最终分类器
   ↓
测试集：只评价一次，生成该折最终预测
```

重新拟合特征排名可能改变具体入选列，但选择器类型和目标维度已经由验证集固定。
因此测试标签从未参与特征选择；若看完测试结果再更换方案，就会形成测试泄漏。

## 两阶段候选搜索

第一阶段不做列级特征选择。每折对11个完整特征组分别训练逻辑回归、随机森林和
HistGradientBoosting三个分类器，共33个候选。每个特征组取三个分类器中的最高验证
accuracy作为初筛成绩，成绩最高的三个特征组进入第二阶段。代码没有预先只使用RF和
HGB；本次结果中RF/HGB较常晋级，是因为它们的验证表现通常高于逻辑回归。

第二阶段只处理晋级的三个组，并比较五种选择器（ANOVA、互信息、L1、随机森林重要性、
mRMR）、小于组完整维度的候选维度，以及全部三个分类器。`random_forest`既可能是给
特征列排名的选择器，也可能是最终分类器，两个角色相互独立；HGB只作为分类器。

最终冠军从第一阶段完整维度候选和第二阶段降维候选的并集中产生。因此完整特征组仍然
可以胜出；Fold 3的 `non_edr_with_hrv + none + 92维 + random_forest` 中，`none`
表示没有进行列级特征选择。
